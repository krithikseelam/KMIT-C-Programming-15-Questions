## 📂 What's Included?

This repository contains **only the `.c` program files** for all 15 questions.

There are **no pre-compiled executable files** included.

After downloading or cloning the repository, **compile the programs on your own machine** before running them.

The programs should work on both **Windows and macOS**, provided you have a C compiler installed.

For example, with GCC or Clang:

```bash
gcc question01.c -o question01
```

or:

```bash
clang question01.c -o question01
```

Then run the program using the appropriate command for your operating system.

### 🪟 Windows

```bash
question01.exe
```

### 🍎 macOS

```bash
./question01
```

**Note:** You need to have a C compiler such as **GCC or Clang** installed on your own machine.
